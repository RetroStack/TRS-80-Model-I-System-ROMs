# TRS-80 Model 1 System ROMs - Changelog

## 1.0.1 - 4th Sep 2026 - Additional Individual ROMs

Added individual 8kb binaries for Level II v1.0, v1.1a, v1.1b, v1.2 and v1.3 (+patch). All eight versions carried by the bundles are now also available unbundled. No ROM content changed - these are the same binaries the bundles are built from.

Notes:

- ROM A is identical for Level II v1.1a, v1.1b and v1.2. Those versions differ only in ROM B.
- ROM B for Level II v1.3 (+patch) is identical to v1.3. MattB's patch changes three bytes in ROM A only.
- Level I has no ROM B. `rom_b_L1.bin` is a blank and is now documented as such.
- Fixed the four folder links in the root README, which still used absolute paths.
